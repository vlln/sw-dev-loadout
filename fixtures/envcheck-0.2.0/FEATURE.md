# 需求：给 envcheck 加 --quiet 与退出码 2 的收口

四条，都小：

1. **新增 `--quiet`**：不打印每个缺失变量的明细行，只打印最后那行汇总。退出码不变。
2. **`--quiet` 与 `--rc` 可以同时给，顺序任意**：`envcheck --quiet --rc path` 与 `envcheck --rc path --quiet` 等价。
3. **rc 文件里一行出现 `=` 时，按不可用处理**，退出码 2，错误信息要指出是哪一行。现在这种行会被当成变量名原样接受。
4. **所有退出码 2 的错误信息都必须带上 rc 文件的路径**，让调用方知道是哪份配置出的问题。

约束：

- 现有 CLI 是公开接口，已有脚本会调用它并读退出码与输出。**成功路径与现有的缺失明细输出必须逐字节不变。**
- 变量名的"按首见序、去重"语义不变。
- 不引入第三方依赖；保持只用标准库。
