# 自检的取证动作

**何时读它**：自检第 5、6、15、17 条靠肉眼判不了时；或要审一份别人写的 README、需要给出可复核的结论时。

自检清单本身在 `SKILL.md`；这里只讲**怎么拿到过 / 不过的证据**。每条命令都在 README 所在目录跑，输出为空或全 200 才算过。

## 第 5、6 条：安装块可跑通

1. 抽出全部 `bash` / `sh` / `console` 围栏里的命令块，逐块原样粘进干净目录执行。改一个字符就不算过。
2. 查占位符残留：

```sh
grep -nE '<[A-Za-z_-]+>|YOUR_|your-|xxx|\.\.\.|…' README.md
```

命中的每一处都必须是注释里的说明，不能是要读者自己补的参数。

3. 每个命令块后面要有预期输出（`console` 块或一行说明）。没有输出样子的命令块，读者无法判断自己是否跑对。

## 第 15 条：手写 TOC 与标题一致

```sh
grep -nE '^#{2,3} ' README.md          # 真实标题
grep -nE '^\s*- \[' README.md          # TOC 条目与锚点
```

逐条对：TOC 里每一项都能在标题列表里找到，标题列表里每个 `##` 都在 TOC 里；锚点是标题小写、空格换 `-`、去掉标点的形式。TOC 指向不存在的标题，读者点进去是页面顶部——按不过算。

## 第 17 条：断链与裂图

```sh
grep -oE 'https?://[^ )"<>]+' README.md | sort -u | while read -r u; do
  printf '%s %s\n' "$(curl -L -s -o /dev/null -w '%{http_code}' --max-time 10 "$u")" "$u"
done
```

- `200` 过；`404`、`410` 不过；`403`、`429`、`000` 记"待人工"，用浏览器复核，别直接判不过（反爬与超时都会这样）。
- 相对链接与图片单独核：`grep -oE '\]\([^)h][^)]*\)|src="[^"]*"' README.md`，逐个确认文件在仓库里存在、大小写一致。
- 图片另核 `alt`：`grep -nE '!\[[^]]*\]\(|<img' README.md`，方括号里为空的 Markdown 图片、没有 `alt` 的 `<img>` 都不过。

## 第 3 条：定位句长度

```sh
grep -vE '^[[:space:]]*(#|<|!|$)' README.md | head -3 | awk '{print length($0), $0}'
```

徽章行、图片行、标题行都跳过，第一行纯文本就是定位句。超过 120 字符不过。中文按字符数算，别按字节。

## 审别人的 README：分级

同一份证据，按影响分级，先修 P0：

| 级别 | 判据 | 典型 |
|---|---|---|
| P0 | 读者拿不到可用信息或会被误导 | 首屏没有"这是什么"、安装跑不通、没有任何许可、裂图与断链 |
| P1 | 信息在，但层级或取舍错了 | 实现细节进首屏、逐文件说明、徽章墙、手写测试数字 |
| P2 | 信息对，表达粗糙 | 标题跳级、代码块没标语言、中英文空格不统一 |

交付结论时给三样：级别、证据（哪一行、哪条命令的输出）、修法一句。只给"排版可以更好"不算结论。
