# 自检的取证动作

**何时读**：交付前核对命令、链接、风格或科研事实；审稿时需要可复核结论。清单以 `$_S/SKILL.md` 为准，本页按主题组织，不依赖条目编号。

每项记录通过 / 不通过 / 不适用；执行受限、网络失败、缺少材料记为“未验证”，不能当通过。以下动作在目标 README 所在项目执行，遵守权限与副作用约束，不因自检擅自安装软件、上传附件或下载大数据。

## 风格与语气

- 对照任务要求、主要受众与所选模板，说明采用的主顺序是否合理。
- 极简型：读原始 Markdown，不依赖 HTML 或图片也能找到安装与最小示例。
- 标准型：必要入口齐全，无空章节或不存在的贡献 / 准则 / 文档链接。
- 海报式：核居中定位、分行入口及展示优先；读者能否先看懂价值与具体成果，而非只看到操作教程。布局按内容判断，不机械要求一功能一图或左右交替。素材不足时已主动准备与检查，不以缺素材降格为标准说明文；示意、案例与实测区分。
- 科研型：先论文与引用，再环境、数据、复现与结果；研究局限不能作为“负面信息”删掉。
- 语气独立核对；海报式缺少必需视觉要素应判该风格未达标，不能把这一要求强加给其他风格；手写目录仍按导航需要判断。

## 语言与信息密度

读 `$_S/references/language.md`，检查实际文本，不以“已选择某语气”代替验收。

1. 每段指出新增的事实、动作或必要条件；无新增内容的铺垫 / 抽象评价删除。
2. 图片、图注、表格、正文与提示块交叉核对，同一事实不换说法重复解释。
3. 具体能力与结果替代宣传口号；标题准确指向内容，不为友好刻意改成长句。
4. 示意 / 实测性质就近简短标一次，边界集中说明；步骤独有风险保留在操作前，不以精简为由删除。
5. 海报式默认专业简洁；任务要求友好语气时仍遵守相同密度要求。发现冗余给原句与精简版本，不只报“语气通过”。

## 来源与归纳

- 每种风格有独立 reference 与实际 template；来源分析在 reference，template 是可填充的 README，而非写作教程。需要核对归纳时查看固定原文，不靠仓库名或机构名推断风格。
- Profile、通用模板、项目 README 不混用；混合型样本可有多个取向，不硬塞互斥分类。
- 原文自述能力不等于实际验证；记录“观察到的结构”“归纳建议”“本 skill 风格约定”的区别。
- 模板从真实来源归纳结构，正文采用目标内容槽位，不编造项目、论文或指标；来源资源不等于目标资源。
- 只分析结构和短摘；复用实现、图片和素材另核许可与署名，公开可读不等于任意复制。

## 模板与命令

1. 搜索 `{{`、`}}`、`YOUR_`、省略号和编辑注释；逐处判断是否为模板残留。HTML 标签或明确解释过的使用者需填写的参数不能仅凭模式命中判错。
2. 识别真正要求读者执行的命令；`console` 通常是输出，不要把输出行当命令执行。
3. 在有权限的隔离环境执行最小主路径；替换真实示例所需的字符也算命令未能原样跑通。需要使用者的数据 / 账号的步骤单独说明。
4. 将可观察结果与文档对照。静默命令可用退出状态或产物说明，不要求每条命令贴终端输出。
5. 区分“预期结果”和“实际运行结果”；运行条件不足时报告未验证，不能伪造输出。

## 标题、目录与定位

模板标题允许按任务改名、合并、拆分或删除可选节，不要求逐字匹配。用文本搜索列出成品标题与手写目录，核对必要内容未丢失、导航已同步，逐条检查跳级、重复标题和渲染平台生成的实际锚点；emoji 同样可能改变锚点。不要假设所有锚点都只是“转小写 + 空格换连字符”，中文、标点与重复标题须按目标渲染平台核对。

首屏定位建议 ≤120 字符，按字符而非字节计数；它是否准确比机械长度更重要。精选导航不是完整 TOC，但每个入口都要存在。

## 链接、图片与徽章

- 从 Markdown 链接（含引用式）、HTML 的 href / src / srcset 提取目标；简单正则不能代替完整检查。
- 相对资源：以目标文件目录解析，确认文件存在、大小写与片段锚点正确；排除作者机器的绝对路径。
- 外链：请求后记录状态；404 / 410 为失败，403 / 429 / 超时为未验证，必要时在浏览器复核。重定向应到真实目的地，不只检查状态码。
- 图片与徽章都有有意义的 alt；徽章链到证据来源，数量与用途合理。多枚样式协调，语义色可以不同。
- 未采用首图或其他可选媒体时，对应检查为不适用，不因空结果声称验证过图片；功能展示所需的真实证据仍单独核对。

## 篇幅与内容去处

逐节问“这节解决哪个目标读者的问题”。短链工具超过约 150 行或 8 个二级标题时优先检查完整参数、架构和贡献细则是否应链接出去；完备型和科研型不按这个数字机械裁剪。

科研指标、复现环境、数据划分和局限是主内容；工程测试通过数量、覆盖率手抄和调试过程仍应链接到相应记录。

## 科研证据

1. 论文 URL / DOI 与项目匹配；BibTeX 的标题、作者、年份、标识来自可核对来源，不凭记忆补齐。
2. 环境声明区分“最低要求”与“原实验环境”；锁文件、硬件条件和运行命令相互一致。
3. 数据与权重链接有访问前提、许可和预处理说明；受限数据不伪装成可公开分发。
4. 每个指标给出数据划分、定义 / 单位 / 方向、配置和出处；论文值、预期值、实际复现值分开。
5. 未运行完整实验时，只报告已核对范围；不把示例跑通等同于论文复现成功。

## 视频与许可

检查当前改动和已有历史中的视频文件；新改动不得把视频加到代码分支。已有历史发现视频时记录问题，不擅自改写历史；README 用可访问的托管 URL / 外链，源素材按重建需要留档。

核对 License 最后、名称 / SPDX 与实际许可证一致；研究材料有独立许可时分别说明。没有许可文件不能直接推断为 MIT。

## 审稿分级

| 级别 | 判据 | 典型 |
|---|---|---|
| P0 | 读者拿不到可用信息或会被误导 | 安装主路径错误、虚构结果、错误许可、关键数据断链 |
| P1 | 信息存在但顺序或取舍妨碍主任务 | CLI 被巨幅装饰挡住命令、科研仓库缺复现条件、徽章墙 |
| P2 | 信息正确但表达粗糙 | 标题跳级、代码块没标语言、语气不一致 |

每条发现给级别、证据位置、修法；未验证项单列，不把“没检查”写成缺陷。风格差异不是错误。
