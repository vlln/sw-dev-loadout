# 风格选择与文件路由

**何时读**：开始写作或审稿前。选择一种主风格，再读取配套风格指南与实际模板。来源证据集中在 `$_S/references/source-catalog.md`。

## 文件职责

- `references/<style>.md`：描述适用场景、默认语气、信息顺序、来源归纳、裁剪方法与验收要求。
- `assets/<style>.template.md`：该风格的实际 README 模板，包含可直接沿用的 Markdown / HTML 结构、正文槽位、代码块和必要表格；不承载来源分析或写作教程。
- `references/source-catalog.md`：固定提交、原文短摘、样本分类与许可边界；不向目标 README 注入研究过程。

## 选择与配对

| 风格 | 适用任务 / 默认语气 | 风格指南 | 实际模板 |
|---|---|---|---|
| 极简实用 | CLI、脚本、小型库；短句指令式，尽快跑通 | `$_S/references/minimal.md` | `$_S/assets/minimal.template.md` |
| 标准开源完备 | 公共库、框架、长期维护项目；专业指令式，信息完整 | `$_S/references/standard.md` | `$_S/assets/standard.template.md` |
| 海报式 | 重展示的产品、Web应用、插件、Demo；专业简洁，操作指令式 | `$_S/references/poster.md` | `$_S/assets/poster.template.md` |
| 学术科研 | 论文代码与实验复现；客观严谨，操作直接 | `$_S/references/research.md` | `$_S/assets/research.template.md` |

任务明确指定的风格优先；未指定时沿用合适现状，否则按主要任务选择。用途不明时用极简作为保守默认，受众差异会实质改变结构时才询问。

风格可混合，但保留一个主顺序，不拼接两份完整模板。CLI 可以重展示，SaaS 的开发者 SDK 可以采用标准型，论文 Demo 优先科研信息。海报式保留居中标题与展示优先，首图可选；不把这些布局强加给其他风格。

## 参考源的归类

| 对象 / 取向 | 来源目录 ID | 使用边界 |
|---|---|---|
| 极简任务闭环 | S13 strip-bom；S09轻量区块、S08局部命令示例 | 学定位、输入与结果；不将整个 Worktrunk 称为纯极简 |
| 完备说明 / 任务路由 | S02、S03、S04、S05、S11项目模板、S12 | 学场景、责任、安装验证、参考分流；不继承源项目能力 |
| 品牌展示 | S01、S06、S07；S08 CLI演示、S12 CTA | 部件可迁移，但样本不全采用相同顺序；海报式完整链是本 skill 约定 |
| 论文复现 | S14 NeRF | 学演示与论文配置分开；统计与许可要求另按证据核对 |
| 个人 Profile | S10、S11个人模板 | 只借个人简介、视觉手法与联系入口，不能替代项目安装使用 |

样本可有多个取向。科研分类依据论文身份与复现实验内容，不根据 NVIDIA / Research 等机构名推断；通用模板、项目首页和个人Profile必须区分。

## 标题与呈现选项

模板标题及章节划分都不是固定清单。“看它完成一次任务”是演示区的示例名，可换成具体任务名，也可把演示并入功能展示；“使用前后”是可选比较区，没有比较必要就整节删除；“费用、账号与数据”可改名、拆为“外部依赖”和“隐私”，不适用内容可删除。“快速开始”也可改为“安装与运行”。可合并 / 拆分章节或删除可选节，但应保留读者需要的信息和所选风格的主顺序。改名后同步站内导航、手写目录与实际锚点，包括 emoji 引起的锚点变化。License 名称可本地化，许可信息仍收尾。

emoji 独立于风格和语气：按任务要求启用 / 禁用，未指定时沿用项目惯例，否则默认不用。不需要为这一偏好阻塞写作；任务可单独指定“海报式但无 emoji”。

## 模板填充规则

1. 先读风格指南，再以实际模板为起点；需要精确借鉴来源布局时查看固定原文。
2. 用目标项目事实替换 `{{...}}`：项目名、命令、输出、资源、指标与许可逐项核对。槽位内容不是已存在的功能或文档。
3. 根据实际产品替换代码块语言；模板中的 `sh` 是命令路径，不要求库项目创造CLI。
4. 模板是可适配的成品起点，不是固定版式；按内容选择展示载体与布局，主动准备缺少的素材。删除编辑注释、无内容的可选区块和不存在入口，不因缺现成素材退回其他风格。
5. 核对标题、锚点、链接与媒体；移除成品中的全部模板占位符，不保留来源分析或编辑过程。

模板默认中文，可按目标语言翻译。视觉风格、语气与语言独立：海报式默认专业简洁，任务可独立指定友好语气，不能据此增加口号或解释性废话；科研型可友好讲解但不放松证据门槛。所有风格均按 `$_S/references/language.md` 检查信息增量、重复与措辞，视觉素材中的文字也不例外。

新增风格应建立一份独立风格 reference 与一份实际 template，并记录真实来源。不复制项目身份、品牌、未授权素材、指标或实现承诺。
