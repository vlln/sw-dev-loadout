## 建议成品顺序

论文与代码范围 → Citation → 环境依赖 → 数据 / 权重 → 最小演示 → 论文复现 → 结果解释 → 自有数据 / 局限 → License。

运行演示与完整复现可以作为两个子入口，不能混称同一件事。只有提供完整配方和证据时才宣称论文结果可复现。

### 论文入口与覆盖范围

从作者确认页面取得标题、作者、论文链接与 BibTeX。不要凭记忆拼 DOI、年份或会议接收信息；未发表项目也不能为版式完整而编出版信息。

借 NeRF 的首屏关系，把“论文是什么”和“这份代码做什么”并列交代：训练、评估、渲染、数据处理或仅 Demo。代码对应哪版论文、哪个提交 / release、哪些实验在范围内，按真实材料说明。

方法图可以辅助理解，但不要求海报式的居中品牌首屏或左右交替图文。论文页面、演示、数据和 notebook 是不同入口，链接文字要区分。

### Citation

放作者核实的引用条目，语言标 `bibtex`。没有可核实论文元数据时报告缺口，不用虚构条目示范一个并不存在的成果。

若改编了其他研究代码，引用与代码许可分别说明，不能认为有 BibTeX 就不需要许可证义务。

### 环境：区分演示和实验要求

NeRF 提供 `environment.yml`，并说明自有真实数据需要额外工具。迁移时复用“环境文件 + 任务额外依赖”的层次，不继承它的 TensorFlow 版本。

本 skill 补充的取证要求：

- 依赖安装来自实际锁文件、环境文件或容器入口。
- 原实验硬件不自动等于最低硬件；显存、驱动和耗时不猜。
- CPU演示、单卡训练、多卡实验各自是否被验证要说清楚。
- 环境检查命令必须存在；未执行就标未验证，不能编成功输出。

### 数据与权重：先取得合法输入

借 NeRF 将示例场景、完整论文数据、自有数据前提与预训练权重分开路由。迁移时说明每个入口的用途、所需空间、访问步骤和许可。

数据目录只列使用者必须准备的位置，不介绍全部源码。数据划分、预处理、单位、坐标系和归一化规则按目标任务取证；不是所有研究都应套固定的 train/val/test 目录。

有授权门槛时说明申请，不提供虚构公开镜像。代码 MIT 不代表数据、图像、权重也 MIT。哈希与数据版本有记录才写，不能编校验值。

### 最小演示：让读者看见进展

源文 TL;DR 连续给环境、下载示例、启动训练与 Tensorboard，并指出成功时的浏览器入口。

目标最小演示应交代：所选样例 → 必要准备 → 一条主命令 → 进展观察位置 → 完成产物。长训练的运行中信号与最终指标不同，不能拿“日志在写”当完成。

本指南不嵌入 NeRF 命令，因为它们属于特定旧版本且涉及环境安装和数据下载；写目标 README 时从其真实脚本和配置取得命令，并按授权验证。

### 论文复现：明确与 Demo 的差异

NeRF 原文另指 `paper_configs/`，避免把低分辨率示例冒充论文结果。迁移时显式对照：

| 要素 | 必须说明的差异 |
|---|---|
| 配置 | 演示配置和论文配置的入口及用途 |
| 输入 | 数据版本、划分、预处理和评估范围 |
| 计算 | 训练步数、分辨率、硬件条件与实际预算 |
| 选模 | checkpoint来源、选择标准、是否使用测试集 |
| 随机性 | 目标确有随机过程时记录种子与重复方式 |
| 输出 | 产物位置、评估命令、汇总与核对方法 |

这张表是本 skill 的复现检查建议，不声称 NeRF 原文已提供所有项目。没有记录的项标未验证或缺口，不补假的“标准设置”。

### 结果与局限：来源值和自己的值分开

原文以训练产物 GIF 和论文配置入口帮助读者判断；本 skill 进一步要求数值结论有出处：

- 论文报告值必须对应论文表 / 图和协议，不能变成实际复现值。
- 实际复现值必须有运行记录，未运行就写未运行，不填示例分数。
- 指标有单位、方向、数据划分、聚合方式；均值、标准差、区间不能混用。
- 消融只在实际完成时报告，保持比较条件；缺算力不是负面结论。

如使用结果表，列“方法/配置、数据与协议、论文出处、复现记录、偏差说明”，有证据才填数值。宁可留待核缺口，也不要造一张漂亮的指标表。

局限包括不支持的输入、未评估的泛化、数据限制与复现偏差。它们是研究有效范围，不是应删掉的负面宣传。

### 自有数据与结束

借 NeRF 的“有没有姿态”分流：只说明读者接入所需协议与额外工具，不把论文全部数学推导或模型实现复制进首页。

贡献 / 复现问题入口要求提交配置、环境与去敏记录；不能上传受限数据或凭据。License 收尾并区分代码、数据、权重和第三方材料，是本 skill 额外约定，不能从仓库品牌推断。
